相邻相同语法点：无
解析要点： ① if 条件状语从句：主将从现，主句用一般将来时 (will travel / will pass)，从句用一般现在时 (is / rains / go)；
② need to do：情态动词 need 后接动词原形，主语为复数或第二人称时 need 不加 s (need)；主语为第三人称单数时 need 加 s (needs)；
③ It is + adj. + to do：句型 It is + 形容词 + to do sth.，其中 to do sth. 是真正主语；
④ 疑问词 + 不定式：how/what/where + to do 作宾语 (how to use / what to do / where to go / where to stop / how to get)；
⑤ be worth doing：worth 后必须接主动形式的动名词表示被动意义 (worth visiting / worth reading / worth taking / worth trying)；
⑥ Why don't we/you/they + do：后接动词原形 (take / go / try / stop / read)。
