fix(paperViewer): 切题定位动态 zoom - 解决 bbox 跑到屏幕外问题

问题：第13题蓝色定位框仍跑到屏幕下方
原因：上一版 jumpToBbox 使用 fitToContainer 的小 zoom 缩放图片（2000x3000 → 368x552），
  当 bbox 在图片中下部（bboxCenterY_px * zoom > ch）时，panY 居中后
  bbox 屏幕 y = panY + bboxCenterY*zoom > ch，框超出屏幕底部。
  实测 9 个真实场景中 9/9 都跑出屏幕（偏 451-1987px）。

修复：jumpToBbox 改为动态计算 zoom：
  - zMax = min(ch/bboxH, cw/bboxW, 5)：保证 bbox 完整可见
  - zMin = max(...居中约束...)：保证 bbox 可居中（panX/panY 在图片偏移范围内）
  - 选 z = (zMin <= zMax) ? zMin : zMax
    · 可居中时取 zMin（精确中央）
    · 否则取 zMax（完整可见）
  - 保留用户主动放大的 zoom（切题时不缩小让用户迷失），但仅当 zoom <= zMax
  - 兜底裁剪：bbox 仍被裁剪时调整 panX/panY 让 bbox 完整可见

测试：scratchpad/test_bbox_jump.mjs 13/14 通过
  - 13 个 case bbox 精确居中（合法 y 范围）
  - 1 个 case (y=0 顶部) 数学不可能严格居中，bbox 在屏但偏顶部
  - 用户主动 zoom 1.5/2.0 时正常降级到 zMax（避免 bbox 越界）
