feat(脏数据): 修复题目类型后台扫描+修复按钮

新增「修复题目类型」按钮（WorksheetManagement 顶部），供老师一键清洗
老 prompt 上传时残留的 question_type 脏数据（"choice/fill/judge/answer"
整个枚举串 / null / OCR 错字）。

流程：
1. 点击"修复题目类型"打开对话框
2. 选择范围（全部练习册 / 单本），先"扫描脏数据"预览
3. 确认后批量按启发式归一：options 非空→choice，含____→fill，
   含对/错→judge，其它→answer

后端：
- worksheetFixService.js 新增 scanDirtyQuestionTypes / fixDirtyQuestionTypes
  启发式规则与前端 normalizeType 保持完全一致（避免双端漂移）
- routes/worksheets.js 新增 POST /fix-question-types/scan + /fix-question-types
  路径固定在 :id 通配前，避免被吞掉
- 迁移 043 放宽 questions.question_type CHECK 约束，允许 'judge'
  （之前 schema 仅 IN ('choice','fill','answer')，会拒绝判断题写入）

UI：
- WorksheetManagement.vue 顶部加绿色"修复题目类型"按钮
- 对话框支持范围选择、扫描预览（前 20 条样例）、确认执行、
  结果分布统计（choice/fill/answer/judge 各几条）+ 错误列表
