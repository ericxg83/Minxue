## 一、循环机制（怎么接着跑）

**一句话**：每轮 = 做一件具体的事 → 过四道闸 → 提交推送 → 在对话里交报告 → 才允许开下一轮。

### 1. 接力锁 `_loop_state.json`（仓库根，已被 gitignore）
`{ state:"running"|"finished", round, startedAt/finishedAt, note }`。
- 接手第一件事：读它。`finished` → 开工（`round+1`，写 `running`）→ 执行 → 收尾推送 → 写 `finished` → 交报告。
- `state=running` 时任何新触发的会话**立即静默退出**，防重复劳动。

### 2. 一轮的「完成定义」
修复落地 → 测试成功 → 推送；或提案发出并记录在案。不允许同一次会话连吞多轮不上报。

### 3. 四道闸（推送前必须全过，冒烟不过不推送）
1. `npm test` 全绿（当前基线 **1536 全绿**）。
2. lint 无**新增** error（基线 **14 errors / 153 warnings**，历史遗留 14 个 error 不动）。
3. 构建成功且**隔离**：`CODEBUDDY_SAFE_DELETE_ENABLED=0 npx vite build --outDir dist_nightly_YYYYMMDDrNN`（绝不清/写 `dist/`）。
4. **真机级冒烟**：把隔离产物 `npx vite preview --port <端口>` 跑起来，用浏览器自动化实测移动端首页 + 工作台真渲染（挂载点有子节点、innerText 有真实文字、0 控制台错误、0 个 4xx/5xx）；并跑近几轮的回归验证脚本（见第七节）。
   - ⛔ 本机浏览器窗口常隐藏，`take_screenshot` 必超时 → 冒烟改「JS 求值读 DOM」，指令里明确禁止截图；要肉眼看图用 `@napi-rs/canvas` 本地栅格化。

### 4. 自决权三级
- **A 级（直接干）**：行为保持型缺陷修复 / 死代码清理 / 顺手化 / 文档。**A 级 + 四道闸全过 → 直接 `git add/commit/push` 到 `main`，无需请示**（负责人 2026-09-30 明确授权）。
- **B 级（提案等确认）**：产品向决策。
- **C 级（只提案，永不擅自动手）**：DB Schema/迁移、批改主流程（`server/worker.js`）设计、错题生命周期/合并、重练组卷口径、掌握度口径、练习册质量闸、judgements 语义、公共 API 行为、任务状态机、判题/答案解析里的正则与转义、写生产库、批量付费 AI/OCR（>5 次）。

### 5. 回归锁纪律（出过事故的铁律）
- 新增/修改逻辑**必须带回归测试**，且测试要**反向自检**：套在 `git show HEAD:<file>` 的旧版本上必须判红，否则是空锁。
- ⛔ **反向自检脚本里绝不能 `spawnSync` 调用 git**（Windows 上稳定 EBUSY，r89–r93 每轮各踩一次）→ 先用 shell 把旧文件导出到 `_rNN_old/` 再读文件。
- 「0 控制台错误」抓不到最常见的两类「点了没用」：① 点了白屏只打 vue-router **warning**；② 点了没反应只打 Vue **warning** → 必须另加**源码级入口锁**。

### 6. 负责人节奏硬要求（长期记忆已固化）
- 每轮「做完 → 四道闸 → 提交推送 → 在对话里交付报告」之后才开下一轮。
- **需拍板的事编号成表、主动呈报**，别只写进仓库文档就算汇报过。
- **批量写库/批量改文件前，先抽样肉眼验证“检测器”精度**（r79/80 两次实测自动判据精确率仅 ~12%，盲做会毁九成正常数据）。
- **写文件的命令绝不能用 `… | Select-Object -First N`**（PowerShell 会提前终止上游 node，把文件截空；要 `> file 2>&1` 再读）。

## 六、最易踩的硬纪律（一页速查）

- ⛔ 白板激光笔**绝不进 `startStroke`/`appendLivePoint`，绝不写 `localStrokes`**（导出 PNG 只读 `localStrokes` ⇒ 天然不含光点）。
- ⛔ 反向自检脚本**禁止 `spawnSync` git**（Windows EBUSY）→ 先 shell 导出 `_rNN_old/`。
- ⛔ 白板**内容必走 `MathRender`**；导出离屏层必须 `Teleport to="body"` 且**不能加 `z-index:-1`**；标题纯文本不走 MathRender（`10-03` 会变 `10 − 03`）。
- ⛔ `saveStrokes()` 按 `current` 算键 ⇒ 任何换可见题单的动作**必须先落盘旧题**（`onPageHide` 也补一刀）。
- ⛔ 改裁片/产物必须把「同一事实的全部表达字段」一次对齐（如 `geometry_image_url` 与 `image_bbox` 一起改）。
- ⛔ 判模型能否读图只能实测（`input_modalities` 撒谎）；AI 调用必关代理；离线脚本禁 `noBackup:true`。
- ⛔ 答案引擎：`parent_stem` 必进引擎输入；引图无配图先预判不解析；答案空/缺条件先查 `parent_stem` 非空再归因「AI 能力」。
- ⛔ 含 AI/长事务 POST 必须 `apiRequest(p,opts,1)`；错误体 `{error,message}`，前端读 `err?.payload?.message`。
- ⛔ 判分/校验器只许加规则/测试、不得放宽；判分器两个解析函数不能单独改。
- ⛔ 错题「同一题」走 `questionIdentity.js`；变式题不进重练卷/组卷。
