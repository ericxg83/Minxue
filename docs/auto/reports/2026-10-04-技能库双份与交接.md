## 五、交接

`docs/auto/lanes.md` 里「**流程沉淀与 skill 维护**」赛道（认领方：常驻巡检会话）写明的范围是
`~/.workbuddy/skills/minxue-*/SKILL.md`。因此**本文库不擅自改动那一份**，只提供：

1. 上面 §4 的逐条清单；
2. 可直接复用的体检命令：

```bash
cd /d/Minxue_App_V3
node scripts/check-skill-refs.mjs                      # 两份一起扫
SKILLS_DIR="$HOME/.workbuddy/skills" node scripts/check-skill-refs.mjs   # 只扫你那份
```

3. 本文库踩过并已修好的同类问题清单（可对照自查）：
   - 路径前缀写错（`scripts/` → `server/scripts/`）—— 照抄命令必 `Cannot find module`
   - 引用了每轮临时件（`_*` 不入库）却写成「现成工具」
   - **行号引用必然漂移** —— 建议把 `文件:行号` 换成「文件 + 符号名」
   - **反向自检**：断言套在旧版上必须判红，否则是空锁
     （实例：`/\.catch\(e =>\s*$/` 漏 `m` 标志 ⇒ 新旧版都通过）
