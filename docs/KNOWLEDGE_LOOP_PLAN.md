# 敏学 · 知识点驱动学习计划（V3）

> 修订日期: 2026-08-09
> 定位变更: 核心意图 = **通过知识点快速制作精美讲义**，知识点驱动闭环是数据来源，讲义是最终产出物。

---

## 一、核心意图

> **老师选中知识点（或系统推荐薄弱点）→ 一键生成精美讲义 → 预览 / 微调 / 下载（PDF/Word）**

- **快速**：从选知识点到出讲义，全程分钟级，无手工排版。
- **精美**：讲义有模板化设计（封面/配色/排版/公式渲染/几何图/留白/分页），可复用、可定制。
- **数据驱动**：知识树 + 错题数据（典型例题、错因）+ AI 生成（概念讲解、变式题）自动组装。
- 后续再叠加变式题、掌握度、英语接入，但**讲义始终是第一产出物**。

## 三、阶段 0：定架构（先定再实现，不改代码）

产出设计文档，定死以下 8 项，再让 AI 实现。

### 1. 数据结构（新增 5 张表，走 `server/migrations/014_*.sql`）

| 表 | 关键字段 | 作用 |
|---|---|---|
| `knowledge_points` | id, parent_id, name, subject, level, sort_order, synonyms jsonb | 知识树（学科→板块→章节→知识点） |
| `question_knowledge` | question_id, kp_id, role(primary/secondary), weight | 一题多知识点归属 |
| `knowledge_mastery` | student_id, kp_id, mastery(0-100), history jsonb | 学生知识点画像 |
| `variant_questions` | source_question_id, kp_id, content, answer, analysis, strategy | AI 变式题 |
| `handouts` | id, title, kp_ids jsonb, template_id, content jsonb, status | 已生成讲义存档（可复用/二次编辑） |

### 2. 讲义模型（核心）

精美讲义 = 模板化模块组装：

```
封面（标题/学科/年级/时间/教师信息/配图）
├─ 学习目标（知识点对应课标要求）
├─ 知识讲解（概念 / 公式 / 易错点 / 方法总结，AI 生成 + 公式渲染）
├─ 典型例题（从错题库取样：题干 + 解析 + 错因点评）
├─ 变式练习（AI 生成 2-3 道同类/变式题）
├─ 随堂练习（留白作答区）
└─ 参考答案与解析（独立分节/可折叠）
```

### 3. 精美讲义渲染引擎

- **Web 讲义页**（React/Vue）作为主渲染：Tailwind + KaTeX 公式 + 几何 SVG（复用现有 `tikz/svg` 资产）+ 统一配色/字体/封面设计。
- **导出**：Web 页 → `pdfGenerator` 打印导出 PDF；保留 docx 通道。
- **模板系统**：`template_id` + 主题色/字体/封面样式可配置，模板数量从 2-3 个起。
- 讲义页支持**在线微调**（删减模块、替换例题、编辑讲解文本）后再导出。

### 4. AI Pipeline

- 在 `worker.js` Step 8 后追加「知识点归属」步：`ai_tags → 归一化到知识树节点`（同义词映射 + 置信回退本地字典）。
- 新增「讲义生成」异步任务：知识树 → 拉取典型错题 + 调 AI 生成讲解/变式 → 组装 `handouts.content`。

### 5. 知识点体系

- 数学初中完整树种子数据（几何→三角形→全等/相似…，代数是另一枝）。
- 同义词映射表：`根判别式→判别式`、`一元一次`→…。
- 从 `localTagger` 平铺字典升级为树结构。

### 6. 变式题生成规则

4 种策略：改数字 / 改条件 / 逆命题 / 情境迁移；AI 必须返回结构化 JSON（题干/答案/解析/策略），入库 `variant_questions`。

### 7. 掌握度计算（后置，阶段 2 启用）

建议公式：正确率 × 难度加权 + 连续 2 次正确进阶 + 时间遗忘衰减；仅作讲义推荐依据，不阻塞讲义生成。

### 8. 与现有系统关系

- 讲义数据源 = 知识树 + `wrong_questions` 错题样本 + AI 生成模块。
- 重练卷维持现有 `generated_exams`，且当前口径是**只练错题**：重练卷题目只来自 `wrong_questions`，不掺变式题（见 `docs/wrong-question-system.md` 的「重练范围限制」）。"按知识点生成变式重练卷"是被搁置的后续设想，放开前需单独评审重练归因与掌握度口径。
- 掌握度用于"推荐本周该讲哪些知识点"，反哺讲义推荐。

## 四、阶段 1（MVP）：数学知识点 → 精美讲义

1. 建 5 张表 + 数学知识树种子数据。
2. `server/services/knowledgeService.js` + `server/services/handoutService.js`：
   - 知识点归一化 / 查询 / 推荐薄弱点
   - 讲义组装（模块化）+ AI 讲解/变式生成任务
3. **精美讲义渲染引擎**：
   - Web 讲义预览页（模板 + 封面 + KaTeX + 几何图 + 配色）
   - 导出 PDF（复用 `pdfGenerator`），保留 Word 导出
4. 前端入口：教师选知识点（或选"薄弱知识点推荐"）→ 一键生成 → 预览/微调 → 下载。
5. 验收：从选知识点到下载精美 PDF 讲义 ≤ 3 分钟；至少 1 套模板效果美观；公式/几何图渲染正确。

## 五、阶段 2：数学闭环完善

- 一题多知识点权重 → 掌握度分摊算法 → 知识点画像页（进度条）。
- 变式题质量评估 + 题库积累 → 支持"变式重练卷"。
- 讲义推荐：按班级/学生薄弱知识点自动推荐"补强讲义"。
- 掌握度可视化（判别式 ████████░░ 80%）。

## 六、阶段 3：接入英语

- 复用全部底层（知识树 / 讲义引擎 / 模板 / 导出），仅换：
  `English Analyzer` / 英语知识体系 / 英语出题器。
- 新增**文章级上下文分析**：阅读类题目需要段落/全文语境，现有单题分析器需扩展。
- 讲义模板补充英语专属模块（生词表、长难句解析、篇章结构）。
