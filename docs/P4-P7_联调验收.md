# P4-P7 联调验收手册

> 适用代码：讲义引擎 / 变式题 / 薄弱点推荐 / 知识点闭环
> 本地启动：`npm run dev`（前端 5173）+ `npm start`（后端 4000）
> 前置：执行过 `migrateKnowledgeTables`（migration 036）和 `migrateVariantQuestions`（migration 037），启动时自动跑

## 1. 端到端闭环（人工走一遍）

### 步骤 1：上传作业 → 批改
- 在 workbench 上传任意数学作业
- 等批改完成（done）
- 打开 `wrong_questions` 表，能看到错题被写入

### 步骤 2：知识点归一化（自动）
- 批改完成后 worker 末尾会调用 `syncQuestionsKnowledgeAndMastery`
- 看服务端日志，应出现：
  ```
  📌 [Knowledge] 知识点归一化+掌握度同步: 关联 N 题, 掌握度更新 N 题, 跳过 N 题
  ```
- 查数据库：
  ```sql
  SELECT * FROM question_knowledge WHERE question_id = '<某错题id>';
  SELECT * FROM knowledge_mastery WHERE student_id = '<学生id>';
  ```
  应有记录

### 步骤 3：成长中心看真实数据
- 打开 `http://localhost:5173/workbench/growth`
- 顶部"知识点掌握率"卡片显示数字（不再 0）
- "知识点掌握情况"表格显示按掌握度升序排列的薄弱项
- **薄弱知识点推荐**卡片显示 TOP 8 推荐（按优先级排序，紧急项红色高亮）

### 步骤 4：错题卡变式题
- 错题本点开任意一张错题卡
- 底部"变式题"按钮展开 → "生成变式题（AI）"
- AI 调用完成后看到 4 道变式（改数字/改条件/逆命题/情境迁移）
- 4 道变式同时入 `variant_questions` 表
- 变式题只作讲义与教学素材，**不得出现在错题重练卷里**；验收时确认「创建重练」生成的卷子题目全部来自 `wrong_questions`

### 步骤 5：生成讲义
- 成长中心右上"一键生成讲义"按钮 → 跳到 `/handout`
- 讲义页应显示封面 + 目录 + 多个知识点页（含知识讲解、典型例题、变式练习）
- 数学公式（$...$）应正确渲染（KaTeX）
- "导出 Word"按钮 → 下载 docx → 排版与 Web 预览一致

|---|---|---|
| GET | `/api/knowledge/mastery?studentId=` | 学生知识点掌握度 |

## 4. 常见问题

**Q: 改了 knowledge_points 但前端还是显示旧的？**
A: 调一次 `POST /api/knowledge/cache/clear`（运维端点），下一次请求会从 DB 重载。

**Q: AI 生成变式题失败 / 返回空？**
A: 检查 `knowledgeService.matchKnowledgePoints` 是否能识别该题 ai_tags 对应的知识树节点；
若 tags 全为 "未分类"，先用 `localTagger.js` 的本地字典兜底；都不行则返回空（不阻塞主流程）。

**Q: 讲义 docx 中文乱码？**
A: 字体设置为宋体/黑体（在 handoutDocxService.js 顶部常量）。docx 内部是 UTF-8，正常打开 Word 应正常显示。
若仍乱码，检查本地 Word 是否缺失中文字体。

**Q: KaTeX 公式不渲染？**
A: 打开 DevTools 看 console，确认 `katex` 已加载。报错的话看 `throwOnError:false` 是否生效（应回退到原文）。
